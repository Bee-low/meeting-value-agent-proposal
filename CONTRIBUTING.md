# Contributing

Thanks for helping shape the Teams Meeting Value Agent proposal. The goal is to improve the concept, prototype, and manager-facing value story.

## How to run locally

Open `index.html` directly in a browser, or run:

```bash
npm run dev
```

Then open `http://localhost:4173`.

## Useful feedback

Please focus feedback on:

- Whether the proposal is clear for managers.
- Whether the value score feels fair and explainable.
- Which Microsoft Teams and Microsoft Graph integrations should be prioritised.
- What privacy or workplace concerns should be addressed before piloting.
- Whether the interactive estimator helps explain the concept.

## Making changes

1. Create a branch from `main`.
2. Keep changes small and easy to review.
3. Test by opening `index.html` or running `npm run dev`.
4. Open a pull request with the reason for the change and any screenshots if the UI changed.

## Product principles

- Use role-based estimates, not individual salary data.
- Keep the agent manager-facing and constructive.
- Treat meeting cost as a prompt for better outcomes, not as a blame mechanism.
- Prefer clear agendas, decisions, owners, and due dates over abstract productivity scoring.
